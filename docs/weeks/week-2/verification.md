## Behavior proven locally

- Technical, nontechnical and broad topic fixtures pass through authenticated topic submission, durable job, validation, atomic outline/lesson publication and persisted reads. Every outline has the required metadata/counts; generated lesson content includes headings/paragraphs, relevant code, 4–5 explained MCQs and video queries.
- Concurrent identical course requests create one owned course/job/quota slot. A reused UUID with another topic is rejected. The active-job quota holds under concurrent distinct submissions. Four simultaneous lesson opens and two workers result in one normal provider call for that lesson.
- Invalid module counts, unknown resource IDs, invented URL fields, blank explanations, invalid MCQ indexes and missing video queries are rejected. Invalid lesson content stays null with a null hash. Outline failure leaves no modules/lessons published. One bounded repair can succeed; four exhausted attempts cannot be reset.
- Provider rate limits/errors are safely recorded, then an explicit retry can recover. The SDK transport contract checks schema/model/store:false/timeout/zero SDK retries. A provider promise ignoring cancellation is bounded by the worker deadline.
- Another owner's course/lesson/retry/generate operations return 404. Request UUIDs are scoped by owner. GET and repeated generation POST of a ready lesson reuse unchanged persisted content/hash across database reconnects, without provider work.
- Restart recovery processes expired leases, marks exhausted interrupted jobs failed and fences late results from the replaced worker. Deletion during an in-flight call removes jobs/parent and prevents orphan publication. Simulated storage failure rolls back partial curriculum publication and succeeds on a bounded retry.
- Browser journeys verify generation progress, course and lesson failure/retry, no auto-retry on failed lesson reopening, refresh persistence, highlighted strings, catalogue/null suggestions, quiz explanations, previous/next navigation and cached reopening without another generation POST. Sample/login/protected-route/save/delete/library-error regressions remain passing.
